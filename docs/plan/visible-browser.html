Visible browser, always

The bot's Chrome becomes a normal window you can see. Sign-in happens in that same window, and scheduled runs work while you're away. Implemented (2026-11-11); verified again on 2026-11-12.

What changes

  1. One visible Chrome, named "oxbot". The bot's Chrome opens as a normal window, still driven by oxbot, and is always on. Its profile is named oxbot in Chrome's profile button. It's oxbot's own Chrome profile, not a profile inside your everyday Chrome: Chrome lets only one program run a profile folder at a time. Practice runs and end-to-end tests stay hidden.
  2. Sign in in the same window. oxbot no longer swaps to a hidden Chrome after you sign in, so the session stays in one browser. While you sign in, the bot's browser tools pause: no snapshots, reads or clicks until you press Done. That way the bot never sees what you type.
  3. Scheduled runs while you're away. A schedule you set counts as you asking for the task. The window opens on the Mac and the bot works at the gentle pace. If a site shows a robot check or a "blocked" page, the bot doesn't retry or try to get past it. It stops that part, sends a notice to your phone, and finishes what it can, for example leaving the shopping list in the chat.
  4. Two small fixes from the last test. A bot waiting on you (a sign-in or approval card) isn't stopped as "idle". The rules also say to press Enter after typing in a search box.

Things to know

  • Closing the window is safe. Closing it or quitting Chrome stops Chrome, and the bot's step in progress fails. The bot's next browser step opens the window again, minimized. Closing it during sign-in counts as done, as before, and the bot carries on. You stay signed in, because sign-ins live in oxbot's Chrome profile. Your own Chrome isn't touched.
  • The Mac has to be on and logged in for scheduled runs. A locked screen is fine.
  • Minimized by default. The window opens and goes straight to the Dock. Click it there to watch. For sign-in it comes to the front, and it goes back to the Dock when you press Done. Chrome is launched with its standard flags for keeping background windows running (--disable-backgrounding-occluded-windows, --disable-renderer-backgrounding), because macOS slows down minimized windows. If pages still stall, the fallback is opening the window behind other windows instead.
  • A visible window may still not get past Walmart. oxbot still drives Chrome remotely, and Walmart can see that. If they keep blocking it, the bot stops and tells you. That's when the Agent Gateway or "you fill the cart" comes in.
