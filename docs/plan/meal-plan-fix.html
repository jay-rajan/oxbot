New instructions for Meal Plan

I don't write files. 1. The week at a glance: day, meal, minutes. 2. Each recipe: servings, ingredients with amounts (e.g. 1 lb chicken breast, 2 bell peppers), and numbered steps. 3. A link to the recipe's page, only for a page I actually opened in the browser. Never a made-up link; no link is fine. 4. One grocery list for the week, grouped by Walmart section, with amounts, combined across recipes. It always includes milk, 8 bananas, 3 apples and a healthy snack.
