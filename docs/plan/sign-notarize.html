What the script will do

  1. Finds your identity in the Keychain (or OXBOT_SIGN_ID). None found → today's throwaway signature, with a clear note; nothing breaks for builds on other Macs.
  2. Signs with your ID plus Apple's secure timestamp: the Mac helper, then oxbot.app, hardened, microphone only (no new permissions).
  3. Checks every program inside (Codex, Node, ripgrep, zsh, any new one) carries a Developer ID, the hardened runtime and a timestamp. Anything else stops the build with its name, before Apple rejects it.
  4. Signs the .dmg, sends it to Apple with the oxbot profile and waits. A rejection prints Apple's log of what's wrong.
  5. Staples Apple's approval to the .dmg, so it opens without a network check.
  6. Checks like a new Mac: stapler validate, and Gatekeeper (spctl) on both the .dmg and the app inside it.
  7. Writes the SHA-256 last, for your download page.

Switches: OXBOT_NOTARY_PROFILE (default oxbot); --no-notarize for a quick signed build. No secrets in the repo: only the identity and profile names.

Testing

  • Build arm64 (your Mac) first, notarize it for real, and run the checks above. Then Intel, if you want both now.
  • I don't open the built app: it would use your real oxbot data and clash with the oxbot running on port 7878. You open it once from the .dmg (quit the dev oxbot first) to check it starts, the microphone prompt appears and dictation works.
