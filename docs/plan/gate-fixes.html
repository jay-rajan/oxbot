1. Who counts as the Farm D1

Today any page or program on the Mac that reaches 127.0.0.1 is treated as you, the Farm.

  • When the server starts, it makes a random Farm secret and saves it in the oxbot data folder, readable only by your Mac account.
  • The Mac app reads the secret and opens its window with it. The page keeps it for that window only and sends it when it connects.
  • The oxbot chat terminal reads the same file. oxbot serve prints a link with the secret, the way Jupyter does.
  • Without the secret, a local connection is refused, so a bot clicking a link to 127.0.0.1 gets nothing.
  • Each new pairing shows in every Farm window ("Pixel paired for Sam, just now").

I'm dropping the native Mac pop-up. The secret already limits pairing to the real oxbot window, and bots never drive that window. Say if you still want the pop-up.

2. Which networks phones can use D2 M19

Your note: "how do we know its home. This should be a setting option".

  • Settings → Gates gets Networks phones can use, with an Add this network button. The Farm recognizes a network by its router's hardware address (MAC), so a café can't copy it by using the same Wi-Fi name. The list shows the Wi-Fi name next to it when the Mac can read it.
  • The door opens only while the Mac is on a listed network. It checks when the network changes and every 30 seconds.
  • When the list is empty, the door stays shut and the Gates tab says why.
  • It only accepts devices on your local network: private addresses, no internet ones.
  • The door closes when no phones are paired and no code is showing.
  • OXBOT_GATE_PORT=off turns it off completely.
  • The name phones see on the network is a setting too (default: the Mac's name).

3. Red cards and Herder per person D3 D4

  • Each card remembers who asked. Only that person (on any of their phones) and you on the Farm see it and can answer. Sam's phone no longer sees your cards.
  • Herder keeps one conversation per person, each with its own Claude session and its own chat history. Sam asking "what did Jay ask?" finds nothing.
  • Shared bots stay one conversation, because sharing is the point. Each line shows who said it (see M22).

4. Chats on the phone, with limits M7 M8

Your note on M7: "the phone should get the SQLite DB for conversation over the network. keep reasonable limits".

  • The phone keeps its own small SQLite copy of the chats it can see, filled from the Farm over the encrypted link.
  • Away from home, you can still read past chats. Sending is off until you're back.
  • Limits: the latest 300 messages per bot and nothing older than 30 days, only bots this phone's person can see, and file contents never copied.
  • On reconnect it fetches only what's new.
  • "Forget this Farm" or Remove on the Mac wipes the copy.
  • M7 itself: the Farm page can no longer be loaded twice at once.
  • M8: a message typed while offline stays in the box with "Not connected yet". It isn't silently lost.

The copy sits in the app's private storage, like the pairing. Moving the key into the Keystore (#10) will protect both later.

What was built

crates/oxbot/src/door/ (M10 split)
  • mod.rs: Door::start, refresh, apply, open_now and close_now behind one async lock (M1, M2). Also add_network, remove_network, set_name, start_pairing, pair, check_key, and the Online guard (M5).
  • network.rs: Settings (door.json) and mac_probe (route, arp, ipconfig). is_private_peer lets only local devices in (D2).
  • listener.rs: TlsListener allows at most 64 connections and 5 s per handshake. Conn closes after 60 s idle (M3, M4).
  • pairing.rs: PairingCodes takes the time as an input, so expiry and tries can be tested (M17).
  • http.rs: pair and require_key. A database error answers 503, so the phone keeps its pairing (M12).
  • identity.rs and discovery.rs: the certificate, and the mDNS announcement.
crates/oxbot/src/secret.rs (D1)
  • farm_key: the 0600 file. local_ws_url is used by chat and bots. random_hex, same and write_private (atomic).

crates/oxbot-core (D3, D4, M11, M21, M22)
