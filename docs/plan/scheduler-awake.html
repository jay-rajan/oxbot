Schedules that run, even after the Mac slept

The scheduler already runs on the home computer, checking every minute. Two gaps: oxbot never keeps the Mac awake, and a run missed by more than 2 hours while asleep is only marked "missed", so a Saturday 8 AM plan with the Mac asleep until 11 AM never happens.

What changes

TodayAfter
Plugged inThe Mac sleeps when idle; schedules wait.oxbot keeps the Mac awake while it's on power; the screen still sleeps. A switch in Settings: "Keep the Mac awake while plugged in" (on by default). Uses macOS's own caffeinate -s, tied to oxbot: quit oxbot and the Mac sleeps normally.
On battery, or lid closedAsleep; runs more than 2 h late are skipped.Still asleep (that's right for battery). When the Mac wakes, each schedule's most recent missed run runs once, as long as its next run isn't due yet. Older ones are noted "missed". The chat says "Ran at 11:04 AM; the Mac was asleep at 8:00".
oxbot closed or Mac restartedThe same 2-hour rule.The same catch-up on start. "Open oxbot when I log in" (already in Settings) brings it back after a restart.
Seeing schedulesOnly inside each bot's settings.Settings → Schedules: every schedule you can see, next run, last result (ran, late, missed), Pause, Delete. New schedules still come from asking a bot, with its approval request.

A Mac can't wake itself from sleep for an app without admin rights (pmset schedule wake needs root). So: keep awake on power, and catch up on wake. If you want, I can add an optional "Wake the Mac for schedules" that asks for your admin password once. That's one decision below.

How a run is decided

flowchart TD
  T[Every minute, and on wake or start] --> D{Run due?}
  D -- no --> T
  D -- yes --> L{How late?}
  L -- on time --> R[Run]
  L -- late, next run not due yet --> R2[Run once, say it's late]
  L -- next run already due --> M[Note missed, run the newest]
  R --> N[Answer in the bot's chat, line to your devices]
  R2 --> N

Built and tested

  • Keep awake: a small part of the oxbot server holds caffeinate -s -w <oxbot> while the setting is on, and starts it again if it stops.
  • Catch-up: "run once if the next run isn't due yet" replaces the 2-hour window. The scheduler also checks right after waking (macOS tells apps when it wakes; the minute tick covers it anyway).
  • Settings → Schedules tab with the new design pieces.
  • Tests:
    • Unit tests for catch-up: a run 3 h late runs once; days of missed daily runs run the newest once; a weekly run is late but runs; on time is unchanged.
    • Keep awake: caffeinate starts and stops with the setting and with oxbot.
    • End-to-end: the Schedules tab; a late run says it was late.

Decisions for you

  1. "Keep the Mac awake while plugged in": on by default (recommended)?
  2. "Wake the Mac for schedules" (one admin password, for battery and lid closed): add it as an option, or skip it (recommended for now)?
  3. Runs that start late: run them (recommended), or ask you first if more than X hours late?
