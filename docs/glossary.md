# oxbot words

Decided 2026-11-04. Use these words in everything a person sees: the app, phone app, Settings, cards, messages, README, terms and help. Code identifiers may keep old names (Farm, Gate, Herder, engine) where renaming would only churn; comments should use the new words.

| Say | Not | Meaning |
|---|---|---|
| **home computer** | Farm, server, host | The one Mac where oxbot is installed and everything runs: bots, browser, files, AI connection. |
| **device** ("Sam's phone", "Connect a device") | Gate, client, satellite | A phone, tablet or other laptop on the home Wi-Fi that shows oxbot and sends tasks to the home computer. A phone is never the home computer. |
| **Assistant** | Herder, central bot | The built-in bot that lists, makes and hands tasks to other bots. |
| **bot** | agent, engine, worker | A helper you give tasks to. |
| **private bot** / **shared bot** | — | Only its maker (and the owner) / everyone in the home. |
| **owner** | admin, Farm owner, household admin | The person who installed oxbot and connected the home's AI account. Must be 18 or older. |
| **kid account** | kid profile, minor | A child's account; a parent approves anything risky. |
| **approval request** ("wants to click *Buy*: Allow once · Always allow · Don't allow") | card, red card, amber card | oxbot asking before a bot changes something. |
| **Always allow** | rule, allow rule | Let this bot do this same thing on this same site without asking. |
| **AI model**: Free models · Paid models · On this computer | engine, Codex, OpenRouter loop, provider | What answers the bot. Codex and the relay are never named in the UI. |
| **AI spending** ("$5 a month for Sam", "up to 200 questions a day") | budget, requests, tokens, quota | How much AI the home uses. |
| **Privacy: Free · Private · Stays home** | data policy, ZDR, Local | Free: the AI company may keep what's sent (your details removed). Private: kept by nobody, small cost. Stays home: runs on this computer. |
| **What was sent** | relay log, request log | Exactly what left the home computer for a task. |
| **websites you're signed in to** | sign-ins, cookies, home Chrome, profile | Sites the bots can use as you. |
| **small script** ("This task needs a small script") | coding, shell, sandbox | A short program a bot writes to work something out; it runs only on the home computer, in the bot's folder, with no internet. |
