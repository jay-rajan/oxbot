Simpler settings: what was built

The approved settings plan, built across three branches and merged: the settings screens and icons (settings), the backend cleanup (settings-core), and the Activity record (settings-net). The change touches 49 Rust and UI files: about 3,800 lines added and 1,200 removed.

2 · Call flow: one AI question appears in Activity

sequenceDiagram
  participant Bot as Bot (loop)
  participant Relay as Relay (oxbot-relay)
  participant OR as OpenRouter
  participant Store as Store (net_log)
  participant Page as Settings → Activity
  Bot->>Relay: question
  Relay->>Relay: redact: swap personal details, count kinds
  Relay->>OR: request (bytes_up counted)
  OR-->>Relay: answer (bytes_down counted)
  Relay->>Relay: restore details in the answer
  Relay->>Store: note_ai(row: model, sizes, cost, swapped)
  Page->>Store: list_net_log {kind?} (via server, viewer checked)
  Store-->>Page: net_log {rows, totals, more}
