The app's screens, rebuilt in React

The hand-written page (one 3,300-line file) is rebuilt as React components in TypeScript. The Mac app, the phone apps and the browser all show it: the home computer serves it at /, and the phone apps get it as one file. It looks and behaves like the old page; the old one stays at /old/ until you approve the switch. Also on this branch: only the owner can have private bots.

Results

72 / 72end-to-end tests pass on the React page
237screens pixel-identical to the old page
~1%median difference on the rest (timing text, a toast caught at another moment)
71unit tests for the page's state and logic

Found and fixed while testing: reports opened blank (the frame was filled before its window opened); the "Kind of job" choice wasn't read at Save; the Assistant's red X would have been blocked by the page's security policy; "Connect a device" didn't open the form.

  participant S as oxbot server
  participant W as socket (net/)
  participant St as store (state/)

  S->>W: {"type":"event", …} (typed ServerMsg)
  W->>St: dispatch(server msg)
  St->>St: every area's reducer: chat appends, sidebar marks busy, …
  St-->>C: areas that changed redraw their screens
  C->>W: send(ClientMsg) on a click
  W->>S: WebSocket
